# 🗨️ Real-Time Chat App

A simple real-time chat application built using **React.js, Node.js, Express, MongoDB, and Socket.io**. This app allows users to send and receive messages instantly, just like WhatsApp or Messenger.

## 🚀 Features
- 🔐 **User Authentication** (Signup/Login)
- 💬 **Instant Messaging** with WebSockets (Socket.io)
- 🗂️ **Message History** stored in MongoDB
- 🎨 **Modern UI** with React & Tailwind CSS
- 🌐 **Real-time Updates** (No page refresh needed)

## 🛠️ Technologies Used
- **Frontend:** React.js, Zustand, Tailwind CSS
- **Backend:** Node.js, Express.js, MongoDB (Mongoose)
- **Real-Time Communication:** Socket.io
- **State Management:** Zustand
- **Authentication:** JWT (JSON Web Tokens)
